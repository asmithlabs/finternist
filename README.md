# Finternist

Physician-focused financial health platform. Structured financial intake, balance sheet, cash-flow tracking, and an explainable SOAP-inspired Financial Rounds report.

## MVP v0.1
Build 001 covers registration, Financial HPI, fictional manual data entry, dashboard calculations, and a saved Rounds report. The executable starter scaffold is prepared separately for review and local bootstrapping; it is **not yet committed as a complete Rails application**.

- **[Master specification](docs/MASTER_SPEC.md)** — the authoritative product and engineering spec
- [Agent operating guide](CLAUDE.md)
- [Pre-spec starter notes](docs/superseded/) — superseded, kept for reference only

Phase 0 will add the planning documents the spec requires (§25): PRD, architecture overview,
domain and data model, decision records, roadmap and acceptance criteria.

**Status:** early development. Use synthetic/demo data only. No production financial data or banking connections.
